# apps/web

The React 18 + TypeScript + Vite single-page app used by school staff and admins. Design tokens and shared components live in `src/design/`; Tailwind is configured from `docs/design/tokens.md`. UI words come from the tenant's `labels` dictionary, never hard-coded, and times are shown in Asia/Kolkata. During Week 0 this folder holds only the overview design spike (`src/spike/`); run it with `pnpm -C apps/web dev`.
